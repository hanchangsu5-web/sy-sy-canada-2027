💰 여행 가계부

Travel Expense Manager

현재 개발 중입니다.

여행 중 가족 모두가 사용할 수 있는 가계부 기능을 준비하고 있습니다.

Firebase DB를 연동하여 여러 사람이 동시에 지출을 입력하고 하나의 가계부로 관리하는 것을 목표로 합니다.

예정 기능

  • ✅ 가족별 지출 입력
  • ✅ 날짜별 사용 내역
  • ✅ CAD / 원화 자동 계산
  • ✅ 카테고리별 통계
  • ✅ 총 여행 예산 관리
  • ✅ 가족 전체 지출 합계
  • ✅ 영수증 사진 첨부
